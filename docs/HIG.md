# UniverOS HIG

> **已作废（2026-11-14）**：本文件不再作为界面裁决依据。现行基准是用户提供的 `UniverOS · Satellite` 参考文件——窗口内无标题栏、红绿灯浮在内容左上角（13px / 半透明 / 失焦变灰）、工具以「窗口外缘卫星条」声明式渲染（36px 胶囊、26px 正圆按钮、36px 实心强调色主操作、1.5s 自动收纳）。

## 0. 基调

- 桌面系统，不是炫技 Demo。信息优先，装饰退后。
- 液态玻璃参考（Liquid Glass Lab）只取**几何尺寸与动效曲线**，不引入 canvas 折射/模糊层。
- 黑白线条为主，强调色只用于「可操作 / 已选中 / 进行中」，一屏不超过三处。
- 一律走系统渲染层（`NS.render.*`）与 token，不写一次性样式，不用 Windows 原生控件外观。

## 1. 颜色（只用 `css/tokens.css` 的变量）

| 用途 | 深色 | 浅色 |
| --- | --- | --- |
| 窗口底 | `--bg-win` | 同变量 |
| 面板 / 侧栏 | `--bg-panel` | 同 |
| 菜单 / 弹窗 | `--bg-menu` | 同 |
| 控件底 | `--bg-input` | 同 |
| 悬停 | `--bg-hover` | 同 |
| 正文 / 次要 / 弱 / 更弱 | `--text` / `--text-soft` / `--text-dim` / `--text-mute` | 同 |
| 分隔线 | `--border`（1px） | 同 |
| 强调 | `--accent` | 同 |
| 危险 | `--danger` | 同 |

禁止新造 hex；需要派生时改 token，而不是在页面里写颜色。

## 2. 字体与层级

- 字体：系统栈（tokens.css 已定），不引第三方字体。
- 正文 13px / 行高 1.55；控件文字 11.5–12.5px；小节标题 11px、大写、字距 .06em、`--text-dim`。
- 页面标题 h2 16–17px / 600；行标题 13px / 500–600。
- 数字（尺寸、百分比、温度、tokens）用 `font-variant-numeric: tabular-nums`。
- 不用 emoji 当图标或装饰。

## 3. 尺寸与间距

- 窗口圆角 15px；侧栏/内容圆角 12px；控件圆角 **8px**；胶囊仅限开关（999px）。
- 标题栏高 42px；工具栏高 36–40px；行高 30–34px。
- 内容内边距 16–20px；行与行之间用 1px `--border` 分隔，不叠卡片阴影。
- 分组之间 18–22px；同一组内 6–10px。
- 侧栏宽 180–220px，条目高 30px，圆角 7px。

## 4. 控件（唯一来源 `js/render/controls.js` + `css/ui.css`）

### Button
- 高 30，左右内边距 12，圆角 **8px**，无边框，底 `--bg-input`，字 11.5px `--text-soft`。
- hover：底 `--bg-hover`，字 `--text`；按下 `transform:scale(1.08)`，曲线 `cubic-bezier(.3,.7,.4,1.3)`。
- `primary`：底 `--bg-hover` + 字 `--accent` + 600，不铺整块实心蓝。
- `danger`：字 `--danger`，底 `rgba(255,69,58,.14)`。
- `quiet`：无底，字 `--text-dim`。
- 图标按钮 30×30 正方，图标 14px；图标一律 SVG，不用文字代替图标，也不用图标硬塞进有文字的按钮。

### Switch（胶囊）
- 44×26，轨道 `rgba(255,255,255,.18)`（浅色 `rgba(0,0,0,.16)`），圆角 999。
- 圆头 20×20，left/top 3px，白色，`0 1px 2px rgba(0,0,0,.3)`。
- 打开：轨道 `--accent`，圆头 `translateX(18px)`；按下轨道整体 `scale(1.08)`；过渡 .16s。

### Slider
- 轨道高 **8px**、圆角 4px；未选段 `rgba(255,255,255,.18)`，已选段实心 `--accent`（用 `--pct` 变量驱动渐变）。
- 圆头 14×14 白色圆，`0 1px 3px rgba(0,0,0,.3)`；按下 `scale(1.12)`。
- 数值标签 12px / 600 / `--accent`，右侧对齐，`tabular-nums`，最小宽 46px。
- 滑条宽度默认 130px；在表单里占满一行时外层定宽、输入 `flex:1;min-width:0`。

### 输入框
- 高 32，圆角 8，1px `--border-strong`，底 `--bg-input`，聚焦边框 `--accent`。
- placeholder 用 `--text-mute`，文案不超过 6 个字。

### 分段控制（Seg）
- 容器 `--bg-fill` + 1px `--border`，圆角 8，内边距 2。
- 选中项：底 `--bg-hover`、字 `--accent`、600；不整块实心蓝。

## 5. 导航与选中态

- 应用侧栏（设置、Vault、文件、备忘录）选中项统一：`--bg-hover` 底 + 左侧不描边 + 文字升到 `--text`。**禁止整行实心 accent 铺底。**
- 同一动作只允许一个入口；侧栏不再出现第二个「新建」。
- 应用顶部不再放常驻标题栏与菜单栏：标题交给侧栏头或无标题栏窗口的红绿灯区，菜单整组收进状态栏左上角圆点 `●`，窗口整幅留给内容。
- 工具按钮一律由应用声明、系统渲染成悬浮胶囊（见 5.5），应用内不得自己拼一排按钮。

## 5.5 声明式工具栏

应用只说「要哪些工具」，样式、摆放、宽度让位全部由 `js/render/toolbar.js` 统一负责。

- **声明**：应用实例实现 `getToolbar()`，返回数组；`registry` 里给该应用加 `toolbar: true`，并把 `build` 改为挂载后 `return 实例`（窗口层要拿实例取声明）。
- **项形状**：
  - `{ icon, title, onClick, active?, disabled? }`——`icon` 可传 `NS.render.icons.UI` 键名或 `<svg` 源码；`title` 同时用作 `aria-label`；`active` 打 `.on`；`disabled` 置灰不可点。
  - `'|'` 作分隔符，只在语义分组处用（导航 | 视图/导入/刷新）。
  - `{ primary: true, icon, title, onClick }` 收尾圆钮，一窗最多一颗，永远排最右。
- **胶囊**：`--bg-win` 底 + 1px `--border` + `0 12px 30px rgba(0,0,0,.34)` + 背景模糊；圆角 11、内边距 2、按钮间距 1；默认停在内容区右上（`top:7px; right:8px`）。
- **按钮**：30×30、圆角 8、透明无边框、图标 14px、字色 `--text-soft`；hover `--bg-hover` + `--text`；按下 `scale(1.08)`；`.on` = accent 字 + `--bg-fill` 底；`:disabled` 透明度 .35。
- **分隔**：1×16、`--border`、左右 3px。
- **primary**：30 正圆、accent 底、白图标、`0 6px 18px rgba(77,163,255,.34)`、按下 `scale(.94)`。
- **让位**：窗口把胶囊实际宽度回写成 `--tb-w`（用 `offsetWidth`，别用 `getBoundingClientRect`——入场缩放会量小）。声明了工具栏的应用标题行写 `padding-right: calc(var(--tb-w,0px) + 14px)`，并把行高抬到 48px 与胶囊同心。
- **刷新**：应用状态变了调 `this.toolbarRefresh()`（`Component` 的 `afterRender` 钩子已自动转一次），图标/可用态随状态走，不要另建第二处按钮。
- **无标题栏窗口**：非侧栏应用声明工具栏即 `.window.chromeless`——红绿灯 + 胶囊浮在内容上，顶部 44px 空白作拖拽带（按钮与红绿灯不抢手势），不显示标题文字。
- **禁止**：工具栏里放文字按钮；一个窗口出现第二行工具；应用自己写 `.tb-btn` 之外的按钮样式；同一动作在工具栏和侧栏各放一次。

## 6. 图标

- 24×24 描边 SVG，线宽 1.7，`js/render/svg-icons.js` 统一产出（`wrap()` 生成，`APPS` 是应用图标、`UI` 是界面图标）。
- 有图标的位置不再重复文字；纯图标按钮必须带 `title`/`aria-label`。

## 7. 动效

- 统一曲线 `cubic-bezier(.3,.7,.4,1.3)`；时长 .14–.18s（面板类 ≤ .24s）。
- 缩放类反馈上限 1.12，不做弹跳、不做位移抖动。
- 关闭/打开窗口沿用现有 winman 动画，不另写。

## 8. 文案

- 苹果式克制：说清「是什么」，不解释「为什么」，不重复补一句。
- 提示 ≤ 12 字；对话框正文 ≤ 20 字；按钮 2–4 字。
- 不用「!!」「~」，不卖萌，不用感叹号堆情绪。
- 同一信息只说一次：状态栏说过的，弹窗不再说。

## 9. 禁止

- 自造控件样式、在应用里直接写按钮/滑条 CSS。
- 999px 胶囊套在普通按钮上；实心 accent 大按钮。
- 双重入口、文字当图标、图标配长文案。
- 全屏遮罩式弹窗（用 winman 的 owner dialog）。
- 大面积渐变、发光边框、emoji。

## 10. 每次开发前的 6 条自检

1. 我用的控件是否来自 `NS.render.controls`？有没有自己写 class？
2. 颜色是否全部来自 token？有没有新 hex？
3. 按钮/开关/滑条尺寸是否与第 4 节一致？
4. 有没有出现第二个入口表达同一动作？
5. 文案能否再删一半而不丢信息？
6. 新加的工具按钮是否走 `getToolbar()` 声明，而不是在应用里自己拼一排？
